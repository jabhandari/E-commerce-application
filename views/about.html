E-commerce Web Application

This project is a simple Node.js and Express-based e-commerce application designed to demonstrate backend development concepts such as routing, API design, file uploads, and server-side data handling.

The application allows users to browse available store items, explore product categories, and add new products with optional image uploads.

Key Features

  • Browse products through a simple store interface
  • Filter items by category or date
  • Add new store items using a submission form
  • Upload product images using Cloudinary
  • RESTful API endpoints for items and categories

Technologies Used

  • Node.js – backend runtime environment
  • Express.js – server framework and routing
  • Multer – handling file uploads
  • Cloudinary – image storage and hosting
  • JSON – lightweight data storage for items and categories

Purpose of the Project

This project was built to practice backend web development and understand how a basic e-commerce system works. It demonstrates how a server can manage product data, handle form submissions, and expose API endpoints for accessing store information.

Future improvements may include connecting the application to a database, implementing user authentication, and building a modern frontend interface.
